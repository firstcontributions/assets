Welcome to the First Contributions Assets repository! 🎉

This repository hosts the image and media assets used in the First Contributions tutorials. By separating these assets into their own repository, we aim to keep the main repository lightweight and focused on content, while this repository manages the necessary visuals.

📂 Repository Contents
This repository includes:

Images: Visual aids such as screenshots and diagrams.

Tutorial Assets: Media files used in various tutorials.

📌 Purpose
The primary goal of this repository is to:

Provide a centralized location for all media assets.

Reduce the size of the main First Contributions repository by offloading media files here.

Ensure that tutorials remain up-to-date with the latest assets.
