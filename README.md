# First Contributions Assets

This repository contains assets used in tutorials for the First Contributions project.

## Overview

This repository stores images, media files, and other resources used in tutorials for the First Contributions project.

## Usage

These assets are referenced in the First Contributions tutorials and documentation.
They are not intended to be used as a standalone project.

## Note

These assets were moved to this repository to reduce the size of the main First Contributions repository.
